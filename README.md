# D.R.E.A.M. Track

Mingjian Zhang 的 GitHub 个人网站，整合 Moonshot Tangible Lab（MTL）与 Moonshot Interaction Lab（MIL）的愿景、研究方向和项目方法。

## 页面

- `/`：D.R.E.A.M. Track 总览
- `/mtl/`：Moonshot Tangible Lab
- `/mil/`：Moonshot Interaction Lab

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

改版合并到 `master` 分支后，GitHub Actions 会自动构建并部署 GitHub Pages。
